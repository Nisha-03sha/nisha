3. Interactive Data Structure Sandbox

Directly test algorithmic operations on the C backend data structures and observe memory pointer transitions.

📥 enqueue(q, order)

Allocates a new Order node and appends it to the REAR of the queue. If queue is empty, FRONT and REAR both point to this new node.

📤 dequeue(q)

Removes the Order node at FRONT. Updates front = front->next. Disconnects node and marks it Completed.

👁️ peek(q)

Inspects the data at FRONT of queue in O(1) time without removing or modifying any pointer references.

⚡ Time Complexity Analysis

• Queue enqueue(): O(1)
• Queue dequeue(): O(1)
• Queue peek(): O(1)
• Linked List Traversal: O(N)

📖 Project Documentation & Academic Details

College Mini-Project Demonstration Guide for Data Structures and Algorithms.

🎯 Project Objective

The primary goal of this mini project is to bridge theoretical data structures (FIFO Queues and Singly Linked Lists) with a practical, full-stack application.

Rather than using static in-memory JavaScript mockups, the business logic and pointer manipulation reside entirely in a compiled C Backend.

📌 1. Queue Implementation (FIFO)

Orders are placed into a FIFO queue. The oldest pending order stays at the FRONT and is served first.

New incoming orders are attached to the REAR with O(1) time complexity. When food is ready, dequeue() serves the front order and shifts the pointer.

typedef struct {
  Order *front;
  Order *rear;
  int count;
} OrderQueue;

🔗 2. Linked List Implementation

Each Order structure maintains a pointer to the HEAD of a dynamically allocated singly linked list of ordered food items.

This ensures that customers can order any number of unique items without memory wastage or fixed array constraints.

typedef struct Item {
  int itemId;
  char name[100];
  float price;
  int quantity;
  struct Item *next;
} Item;

⚡ Frontend to Backend Flow

1. User adds food items and clicks Place Order.
2. Browser sends HTTP POST to /api/orders.
3. C Backend runs malloc() to create the Order and Item nodes.
4. C backend invokes enqueue(&queue, newOrder).
5. UI dynamically updates Queue and DS Visualizer with real memory pointer values!

💻 Running on Windows (GCC / MSYS2)

The project code is fully cross-platform (using WinSock2 on Windows and POSIX sockets on Linux):

# In MSYS2 MinGW-64 terminal:
cd restaurant-order-management/backend
gcc -Wall -O2 main.c server.c queue.c linkedlist.c order.c -o server.exe -lws2_32
./server.exe 8080
# Open frontend/index.html in Chrome/Edge!

🐧 Running on Linux / MacOS

Using standard GCC and Make:

cd restaurant-order-management/backend
make
./server 8080
# Open http://localhost:8080
